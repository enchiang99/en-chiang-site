# 這個資料夾是做什麼的？

以後要上傳一批新照片時，直接把整個 zip 檔（不用先解壓縮）拖到這個資料夾裡，
存檔（commit）之後，GitHub Actions 會自動：

1. 解壓縮這個 zip
2. 把裡面所有照片搬進 `images/` 資料夾
3. 如果檔名跟 `images/` 裡已經有的重複，會自動改名（加時間戳記），不會覆蓋舊照片
4. 處理完自動刪除這個 zip 檔案，並且自動 commit 回 repo

處理完成後，回到 Actions 分頁確認流程是綠勾勾完成狀態，
再去 `images/` 資料夾確認照片都進去了即可。

這個檔案（README.md）本身可以留著不用刪，它不會被誤判成 zip 去處理。
